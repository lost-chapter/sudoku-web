# 0.1.0 (2026-08-06)

## 追加

- 数独で遊べるようになりました
- やさしい・ふつう・むずかしい・難問・最難関の 5 段階から選べます
- 各段階に 1,000 問ずつ、あわせて 5,000 問を収録しています
- マスに入る候補の数字をメモできます
- 選んだマスと同じ数字が盤面のどこにあるかを色で示します
- 選んだマスと同じ行・列・3×3 のかたまりを薄く敷いて見やすくします
- 入れた数字を取り消したり、やり直したりできます
- 途中でやめても、次に開いたときに続きから遊べます
- あきらめると答えが見られます
- マウスを使わず、キーボードだけでも遊べます
- スマートフォンでは、画面いっぱいに盤面を出す専用の見た目に切り替わります
- 端末の設定に合わせて、明るい見た目と暗い見た目が切り替わります
