# 0002 UI ライブラリに Mantine を採用する

## ステータス

採用(2026-08-05)

## 背景

要件は「**UI は最適なライブラリを用いる**」
([プロジェクトの目的](../overview/project-purpose.md) の要件 2)。

**「最適」を判断するには、まず何を任せるのかを決める必要がある。**
数独の盤面(9×9 のグリッド・セル選択・候補の表示・キーボード操作)は
**どの UI ライブラリにも存在しないので自前で実装する**。

したがってライブラリに期待するのは次の 3 つに絞られる。

1. **盤面の外側の部品** —— ボタン・モーダル・選択・通知・タブ・スライダー
2. **実装を助けるフック** —— ホットキー・localStorage・メディアクエリ・開閉状態
3. **アクセシビリティの土台**

そして**自前の盤面 CSS と喧嘩しないこと**が前提条件になる。

調査は [UI ライブラリの選定調査](../reports/2026-08-05-ui-library-survey.md)。

## 決定内容

**Mantine を採用する**(調査時点の最新は 9.5.1 / 2026-08-02)。

- 部品は `@mantine/core`、通知は `@mantine/notifications`、モーダルは `@mantine/modals`
- **フックは `@mantine/hooks` を積極的に使う** —— 特に
  `use-hotkeys`(数字キー・メモ切替・取り消し)と
  `use-local-storage`(進行と設定の保存)
- **盤面は Mantine の部品を使わず、自前の CSS Modules で書く**
- テーマは Mantine の color scheme(`auto` + localStorage 永続化)に任せる

## 判断理由

1. **必要なフックが公式に揃っている唯一の候補だった。**
   数独で要るのはホットキーと localStorage で、
   **他の候補はどれも自前実装か別ライブラリの追加が要る**。
   `@mantine/hooks` は React 以外に依存が無い独立パッケージである
2. **自前の盤面 CSS と最も衝突しにくい。**
   Mantine のスタイルは `@layer mantine` に入るため、
   **レイヤーに属さない自前 CSS が import 順に関係なく常に勝つ**。
   盤面の境界線制御で `!important` を積む事故が起きにくい
3. **アクセシビリティの裏付けが「検証方法まで」公表されている唯一の候補だった**
   (jest-axe による自動テスト + VoiceOver の手動テスト)。
   [画面構成と操作仕様](../ui/screens-and-interactions.md) で
   「キーボードだけで最初から最後まで遊べる」を要件にしているため、ここは重い
4. ダーク/ライトがシステム連動 + 永続化 + フラッシュ防止まで標準で、テーマの実装コストがほぼゼロ

## 採用しなかった選択肢

| 選択肢 | 却下理由 |
|--------|---------|
| shadcn/ui(次点) | フックを一切提供しない(ダークモードすら公式が手書きコードを提示)。加えて **2026-07 に既定の基盤が Radix → Base UI へ変わり、その Base UI が `1.0.0-rc.0` で安定版未公開**。個人開発では「基盤を選ぶ」意思決定自体がコスト |
| Chakra UI 3 | 全部入り gzip 約 300 KB と候補中最大。フックが export されているのにドキュメントが無く、追加要望も "not planned" でクローズ |
| MUI 9 | テーマ切替は最も手厚いが Emotion 必須で盤面 CSS と体系が分かれる。**公式が次期メジャーでの Emotion 非依存化を予告済み**で移行が待っている |
| Ark UI / Park UI | 完全 unstyled のため部品の見た目も全部自作になり、ライブラリを入れる目的が達成されない |

**次点が勝つ条件**: 盤面まで Tailwind CSS で書くと決めた場合、
またはバンドルサイズを最優先する場合は shadcn/ui が有利になる。

## 影響

- ⚠️ **React 19.2 以上が必須になる**(Mantine 9 の peer 依存)。**React 18 へ戻る選択肢は無くなる**
- **盤面は自前実装。** ライブラリの更新で盤面が壊れることは無い代わりに、
  盤面のアクセシビリティは自分たちの責任になる
  ([画面構成と操作仕様](../ui/screens-and-interactions.md) の「アクセシビリティ」)
- `@mantine/core` の全部入り gzip は約 161 KB と小さくない。
  **使う部品だけを import できているかを工程 3 以降で実測する**
- キーボード操作の実装は `use-hotkeys` に寄せる。**素の `addEventListener` を散らさない**
- ⚠️ **Mantine の `variant="subtle"` を使わない**(2026-08-05 決定)。
  文字色が primary(blue-6)になり、**白地で 3.4:1** と本文の目安 4.5:1 を割る。
  **3 回踏んだ**(盤面の入力色・取り消しボタン・難易度の選び直し)。`default` を使う
- ⚠️ **`index.html` に Mantine の色スキーム用スクリプトを置く**(2026-08-05 決定)。
  無いと、保存した選択が端末の設定と違うときに**初回描画で一瞬だけ元のテーマが見える**
