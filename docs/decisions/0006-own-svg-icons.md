# 0006 アイコンはライブラリを入れず自前で持つ

## ステータス

採用(2026-08-06)。**実装済み**(`packages/web/src/ui/Icon.tsx`)

## 背景

発注者から **「UI が文字ベースのボタンなどが多いのでアイコンを積極的に使うように」**
という要望が届いた([ADR 0004](0004-feature-scope-from-client.md) と同じ経路)。

**必要なのは 11 個**である。

| 用途 | 記号 | 用途 | 記号 |
|------|------|------|------|
| ホーム | 家 | 続きから | 三角 |
| あきらめる | 旗 | テーマ: 自動 | モニタ |
| 設定 | つまみ | テーマ: ライト | 太陽 |
| 消す | ⌫ | テーマ: ダーク | 月 |
| メモ | 鉛筆 | | |
| 取り消し / やり直し | 曲がった矢印 | | |

⚠️ **数字キー(1〜9)は記号にしない。数字そのものが情報である。**

## 決定内容

**アイコンのライブラリは入れず、必要な `path` だけを自前で持つ。**

**置き場所は `packages/web/src/ui/Icon.tsx` の 1 ファイル**
(`ui/` は「UI ライブラリのラッパと共通部品」。[システム構成](../architecture/system-architecture.md))。

## 判断理由

**両方を実装してビルドし、実測してから決めた。**

| | `@tabler/icons-react` | **自前 SVG(採用)** |
|--|---------------------|-------------------|
| JS(生) | 350.46 KB(+3.46) | **348.24 KB(+1.24)** |
| **JS(gzip)** | 108.06 KB(**+1.22**) | **107.42 KB(+0.58)** |
| **`node_modules`** | 🔴 **+140 MB** | **0** |
| 記号を足すコスト | 名前を書くだけ | **`path` を 1 つ描く** |
| 体裁の統一 | ライブラリが保証 | **共通のラッパで強制する** |

🎯 **バンドルの差は gzip で 0.64 KB しかない。全体の 0.6% で、決め手にならない。**

**⇒ 決め手は `node_modules` の 140 MB のほうである。**
**5,000 個の索引を持つライブラリを、11 個のために入れることになる。**
CI は毎回これを展開する。

⚠️ **「差が小さいから好きなほうでよい」とはしない。**
**差が小さいと分かったから、別の軸(依存の重さ)で決められる。**
**測らずに決めると、どちらの軸で決めたのかが残らない。**

## 採用しなかった選択肢

| 選択肢 | 却下理由 |
|--------|---------|
| `@tabler/icons-react` | **`node_modules` が 140 MB 増える**。バンドルの差は 0.64 KB しか無い |
| tabler の `path` をコピーして自前ファイルへ置く | **MIT の表示義務が発生し、管理する対象が増える**。11 個なら自分で描ける |
| 絵文字を使う | **端末ごとに絵が変わる**。色も勝手に付き、単色の UI に馴染まない |
| アイコンフォント | **文字として読み上げられる**ことがあり、行き場のない読みが混ざる |

## 記号と文字の使い分け

🎯 **記号は文字に添える。文字を消すのは、代わりが利かないほど狭いところだけ。**

| 場所 | どうしたか | 理由 |
|------|-----------|------|
| **ヘッダの「ホーム」「設定」** | **記号だけ**(`aria-label` で名前を持つ) | **幅がいちばん厳しい**。320px 幅では 3 つ並べると折り返す |
| 🔴 **ヘッダの「あきらめる」** | **記号 + 文字** | **押すと遊技が終わる**。記号だけにすると**「押して確かめる」が起きうる** |
| **スマホの入力パッド** | **記号だけ**(`aria-label`) | 5 列に並べるので文字が入らない |
| ⚠️ **パッドの「メモ」** | **記号 + 「入 / 切」** | **押しっぱなしの状態を持つ**。記号だけだと**色でしか状態が分からない** |
| PC 版の入力パッド | 記号 + 文字 | **幅に余裕がある。文字を落とす理由が無い** |
| ホームの「続きから」 | 記号 + 文字 | 同上 |
| 設定のテーマ | 記号 + 文字 | ⚠️ **「自動」は絵で表せない** |

⚠️ **`aria-label` と見えている文字を食い違わせない**(WCAG 2.5.3 Label in Name)。
**「メモ」は画面から 2 文字が消えるので、`aria-label` を「メモ 入 / メモ 切」にした。**
**見えている「入 / 切」を名前に含めてあるので、音声で「メモ 入」と言える。**

## 影響

- **バンドルは gzip 106.84 → 107.54 KB(+0.70 KB)。** CSS は +0.01 KB
- **依存は増えていない**(`packages/web/package.json` は変更なし)
- **記号を足すときは `Icon.tsx` の `PATHS` に 1 行足す。**
  ⚠️ **体裁(24×24 / 線の太さ 2 / 端は丸)はラッパが強制する。**
  **`path` を足す人が体裁を選べないようにしてある** —— 揃わなくなるのはそこからである
- **押せる大きさ 44px は保っている**(記号だけのボタンは左右の余白で幅を作る)。
  E2E が画面上のボタンを全部走査して見張る
  ([画面構成と操作仕様](../ui/screens-and-interactions.md) の「押せる大きさ」)
