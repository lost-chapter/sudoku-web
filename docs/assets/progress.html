要判断

公開するには、ユーザーの操作が 2 つ要る

1. リポジトリを public にする。lost-chapter は Free プランなので、 private のままでは Pages を使えない（2026-08-06 実測）。コード・ドキュメント・コミット履歴が すべて公開される。 2. Settings → Pages → Source を GitHub Actions にする。 既定の「Deploy from a branch」のままだと、workflow が成功してもサイトが更新されない。
